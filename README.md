# MPPU and Psychological Distress  R Analysis

This repository contains the R analysis for a research project examining the relationship between **problematic mobile phone use (MPPU)** and **psychological distress (KPDS)** among young adults.

The project includes data preparation, descriptive statistics, reliability analysis, Pearson correlation, simple linear regression, and regression assumption testing using **R version 4.6.1**.

**Sample:** N = 150 young adults aged 18–26 years.

**Main finding:** Problematic mobile phone use was strongly and positively associated with psychological distress (*r* = .862, *p* < .001).
